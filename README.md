# Adam Jung Portfolio

Personal portfolio website for Adam Jung, Safety Certification Engineer.

## GitHub Pages upload

Upload these files to the root of `adamjung-safety.github.io`:

- `index.html`
- `style.css`
- `script.js`

Then commit the changes. GitHub Pages will deploy the site automatically.

## Before publishing

In `index.html`, replace:

`YOUR_EMAIL_HERE`

with the email address you want visitors to use.

Career dates and detailed project descriptions are intentionally generalized in this first version and can be updated later.
