Hazardous location certification and engineering evaluation for a gas delivery system using Type Z purge and pressurization.

01 / PROJECT

GASGUARD
Hazardous Location Certification

NRTL hazardous location certification project for industrial gas delivery equipment intended for installation in a Class I, Division 2 environment.

The equipment incorporates a Z-purge enclosure, controller cabinet and process piping cabinet requiring coordinated evaluation of purge protection, electrical components and hazardous-location construction.
